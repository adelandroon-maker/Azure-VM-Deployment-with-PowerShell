# Azure VM Deployment with PowerShell

## About This Lab

In this exercise, I deployed a Windows Server virtual machine in Microsoft Azure using Azure Cloud Shell and PowerShell.

The deployment process included:
- Creating a virtual network and subnet
- Configuring a Network Security Group (NSG)
- Creating a Public IP address
- Creating a network interface
- Deploying a Windows Server 2022 VM

---

## Environment

- Microsoft Azure
- Azure Cloud Shell
- PowerShell
- Windows Server 2022
